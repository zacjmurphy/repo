## Use Guide

1. In Jellyfin, go to dashboard -> plugins -> Repositories -> add and paste this link ```http://raw.githubusercontent.com/zacjmurphy/repo/main/manifest.json```
2. Go to Catalog and search for the plugin you want to install
3. Click on it and install
4. Restart Jellyfin
